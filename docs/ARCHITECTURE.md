# Architecture

> **Seed doc (Phase 1 of doc-drift-prevention).** This file is the referent for
> the doc-invariant tripwire tests. It is intentionally minimal: it carries only
> the snapshots those tripwires lock, so the forward references in the tests are
> honest today. Phase 2 expands this into the full architecture narrative.

The shape is **engine + backend + shells**. The canonical onboarding order and
the prose narrative live in the repo root `CLAUDE.md` and in `docs/` until this
file is fleshed out.

## Snapshots locked by tripwire tests

Each list below is asserted by a `#[test]`. If you change the code, the test
fails with an actionable message and you update **both** the test snapshot and
the matching list here.

### Content handlers (registration order)

Order is load-bearing: ties break by registration order. Locked by
`crates/fetchit-core/tests/doc_invariants.rs::handler_kinds_and_order_match_snapshot`.

1. `etchit/envelope-v1`
2. `image/*`
3. `audio/*`
4. `video/*`
5. `application/zip`
6. `text/html`
7. `application/json`
8. `text/csv`
9. `text/markdown`
10. `text/plain`
11. `application/octet-stream`

### `Rendition` variants

The typed output UI shells dispatch on. Locked by the in-crate
`rendition_variants_match_snapshot` tripwire in `crates/fetchit-core/src/handler.rs`
(in-crate because `Rendition` is `#[non_exhaustive]`).

`Text`, `Image`, `Audio`, `Video`, `Pdf`, `Json`, `Tabular`, `Archive`, `Html`,
`EtchitEnvelope`, `OpaqueBinary`, `Blocked`.

### `EnvelopeKind` variants

The chat wire envelope discriminant. Locked by the in-crate
`envelope_kinds_locked` tripwire in `crates/fetchit-relay-proto/src/envelope.rs`
(`Unknown(u8)` is the forward-compat variant, not a match wildcard).

`Dm`, `GroupChat`, `AdminEvent`, `DeliveryReceipt`, `PrivateGroupChat`,
`X0xdGroupMetadataEvent`, `Reserved6`, `Reserved7`, `PublicPost`, `Unknown(u8)`.

### Workspace crates

The crate list is derived from `cargo metadata`, not hand-maintained. The single
source is `docs/generated/crate-list.txt`, regenerated by
`scripts/gen-crate-list.sh` and drift-checked by `scripts/check-crate-list.sh`.
