fetch>it web

Routes autonomi://<address> links to fetch>it desktop. No network code in the browser — the desktop app does the fetching.

Address bar

Type fetchit in the URL bar, press Tab, then paste a 64-hex address.

Right-click

Select any 64-hex address on a page → right-click → Open in fetch>it.

Don’t have fetch>it desktop yet?

Get fetch>it desktop — without it, autonomi:// links have nothing to open.
