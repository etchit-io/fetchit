fetch>it web

Routes autonomi://<address> and fetchit://<address> links to fetch>it desktop. No network code in the browser — the desktop app does the fetching.

Click a link

Any autonomi:// or fetchit:// link with the copper fetch>it badge opens in the desktop app on click. Nothing to learn.

Right-click an address

When an address is plain text on a page (not a link), select the 64-hex string → right-click → Open in fetch>it.

Address bar

Type fetchit in the URL bar, press Space, then paste a 64-hex address. Works in Chrome, Edge, Brave, Arc and Firefox.

Don’t have fetch>it desktop yet?

Get fetch>it desktop — without it, autonomi:// links have nothing to open.
